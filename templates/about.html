About This Project

The AQI Prediction System estimates the Air Quality Index from pollutant concentrations (PM2.5, PM10, NO₂, SO₂, CO, O₃, NH₃) and weather conditions (temperature, humidity, wind speed).

Two prediction approaches are available: a classical machine learning regression model (the best of Linear Regression, Decision Tree, Random Forest, Gradient Boosting, and SVR, selected automatically by R² score) and a deep learning Artificial Neural Network built with TensorFlow/Keras.

Tech Stack
  • Python, Pandas, NumPy
  • Scikit-learn (regression models)
  • TensorFlow / Keras (ANN)
  • Flask (backend)
  • Bootstrap 5 (frontend)
Pipeline
  • Data cleaning & outlier handling
  • Feature scaling
  • Model training & comparison
  • Best model saved (.pkl / .h5)
  • Served via a Flask prediction API
